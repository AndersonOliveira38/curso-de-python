# 🐍 Curso de Python — Do Básico ao Avançado

Repositório com exercícios e práticas desenvolvidos durante um curso de Python, do nível básico ao avançado, com foco no aprendizado contínuo e no desenvolvimento da lógica de programação.

## 📚 Conteúdo
- **Básico:** Variáveis, tipos de dados, operadores e estruturas condicionais.
- **Intermediário:** Laços de repetição, funções, listas, tuplas, dicionários e módulos.
- **Avançado:** POO, tratamento de exceções, módulos e conceitos avançados da linguagem.

## 🎯 Objetivo
Praticar Python, aprimorar a lógica de programação e consolidar conhecimentos por meio de exercícios práticos.

## 🛠️ Tecnologias
- Python 3
- Git e GitHub
